## VPN Connect v0.2

VPN Connect is an Android client for Sophos Firewall IPsec VPNs.

- Import any Sophos Connect `.scx` file from the ⋮ menu (or open it from a file manager).
- The title line shows "VPN Connect" until a connection is imported, then the imported file's name.
- Connect with your user name and password; the Events tab lists connects, disconnects and failures.
- App ID `com.vpnconnect.app`. English.
- Author: zero.cyfa

### APK package
Download `VpnConnect-v0.2.apk` below, open it on the phone and allow "Install unknown apps" if asked.
